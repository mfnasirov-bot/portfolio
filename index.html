AI Invoice Extractor

Problem: a business receives hundreds of PDF invoices a month in different layouts and languages, and someone types each one into Excel by hand.

Solution: a tool that reads every PDF with Claude AI, extracts the vendor, invoice number, dates, total, and currency, and writes them to a clean Excel file. If anything is unclear, it never guesses: the row is highlighted for a quick human check.

Running cost: about 1–3 cents per invoice.

  • Python
  • Claude API
