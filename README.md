# Murad Nasirov · Portfolio

Personal portfolio site: AI automation tools and AI product visuals.

- `public/index.html`: the site (static, no build step)
- `public/assets/`: images
- `public/projects/invoice-extractor/`: source code of the AI Invoice Extractor sample project
- `vercel.json`: tells Vercel to serve `public/` as a static site

Deployed on Vercel. Every push to `main` updates the live site.
